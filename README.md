# PL topics, revisited

Re-analysis of Greenberg, Fisher & Walker, "Tracking the Flow of Ideas through the Programming Languages Literature" (SNAPL 2015) on the pldb corpus (https://pldb.kirancodes.me/).

Report: `report/pl-topics-revisited.html` (built from `report/template.html` + `out/report_data.json`).

Live report: https://claude.ai/artifact/WLKy8SBGmCUmoGAf25HCRx (private until shared). Open `report/pl-topics-revisited.html` in a browser for the same page.

Run order (Python venv with gensim, bertopic, umap-learn, hdbscan, adapters, transformers, torch, statsmodels, ruptures, scikit-learn; R with `stm`):

| script | what it does |
|---|---|
| 00_fetch_pldb.sh | download the pldb dump into `data/` |
| 01_fetch_openalex.py | OpenAlex ids + reference lists for every DOI |
| 02_preprocess.py | corpus (title+abstract), cleaning, WordNet lemmas, phrases, df filters |
| 03_embed.py / 03b_align_embeddings.py | SPECTER2 (proximity adapter) embeddings |
| 04_lda.py | LDA k-sweep (NPMI, C_v) and the k=20 replication model |
| 05_stm_searchK.R | STM model selection over K |
| 06_stm_fit.R 40 | final STM, venue×year trajectories w/ CIs, OOPSLA DiD |
| 07_bertopic.py | BERTopic over all 24 venues |
| 08_venues.py 40 | JSD, diversity, venue classifier, changepoints |
| 09_related_work.py 40 | citation-based related-work evaluation |
| 10_seplogic.py 40 34 | separation-logic diffusion analysis |
| 11_report_data.py, 12_build_report.py | assemble report |

NLTK data needed: `wordnet`, `omw-1.4`, `stopwords`. `out/` holds the small derived results (topic labels, theta, trajectories, evaluation tables); large artifacts (embeddings, model binaries, the raw dump) are not committed and are regenerated by the scripts.

Data: pldb (dblp metadata CC0; abstracts via SIGPLAN OpenTOC, OpenAlex and Semantic Scholar, copyright of their authors/publishers). Citations: OpenAlex (CC0).
